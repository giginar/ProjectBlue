## Build rule

`verifyAssetLicenses` checks packageable files against an explicit allowlist and SHA-256
inventory. Unlisted files or changes made after verification stop the build.
Only this inventory and `verified-assets.properties` are exempt metadata files. Other
files placed inside `licenses/` are also checked; the directory is not an exemption.
Hashes are stored in `verified-assets.properties`. Documenting a license does not itself
establish rights: a new asset can be approved only after its source and usage rights
have actually been verified. Changes to code-generated visuals require code review.

Future assets must be original, purchased, CC0/public-domain, or licensed for commercial use.
Record the source, creator, license, download URL, and usage/attribution conditions for
each asset. Retain required license text and purchase evidence in an appropriate location.
Do not use Sky Force assets, UI, levels, or distinctive design elements.

## 2026-09-19 audit

The packaged allowlist contains only the five files listed above. Their SHA-256 values are recorded in `verified-assets.properties`; no unlisted image, font, music or sound file is present under `assets/`. Runtime geometry, the Android vector icon and Windows icon generator are original project work and are documented in this inventory. Blue Grid and all three WAV files remain production placeholders despite having clear project ownership. The store asset gaps and replacement requirements are tracked in `docs/ART_DIRECTION.md`, `docs/AUDIO_ASSET_PLAN.md` and `docs/STORE_ASSET_PLAN.md`.

Regenerate assets from the project root: `java tools/GenerateAssets.java`.

The final candidate audit regenerated the five files in an isolated build directory;
all five matched the checked-in files byte for byte. See [the full asset audit](../../docs/ASSET_AUDIT.md)
for hashes, placeholder status, runtime/dependency assets and missing store exports.
All procedural visuals, UI ornaments, Blue Grid font, three audio files and platform
icons are still placeholders. Approved store-only icon, feature graphic and screenshot
exports are present under `store/assets/google-play/ocean-guard/`; no promotional music,
screenshot caption art or third-party asset is present. QA captures under `build/smoke/`
remain generated evidence and are not themselves store assets.

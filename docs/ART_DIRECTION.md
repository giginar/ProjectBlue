# Project Blue art direction

## Visual promise

Project Blue is an optimistic underwater recovery game. Its visual identity combines dark ocean depth, luminous scientific instruments and the gradual return of living color. The interface should feel like an original civilian recovery console rather than a military aircraft HUD. It must not copy the composition, iconography, typography, ships, effects or progression presentation of Sky Force or another game.

The current playable build uses original runtime geometry. This is a deliberate, legally safe prototype style: silhouettes stay readable on a phone, restoration can change color continuously, and no unverified raster art enters the package.

## Palette and hierarchy

| Role | Color | Use |
|---|---:|---|
| Deep ink | `#061827` | Background, highest contrast field |
| Panel | `#0B2939` | Cards and controls |
| Edge | `#1B4755` | Borders, inactive controls |
| Text | `#E4F2E8` | Primary text and high-contrast warning marks |
| Muted | `#7FA8AF` | Secondary information and unavailable states |
| Aqua | `#64E8D2` | Recovery, selection, sonar and positive progress |
| Gold | `#FFC078` | Rewards, attention and telegraph preparation |
| Red | `#F27978` | Damage and active danger |

Restoration moves environments from low-saturation polluted colors toward region-specific living colors. Red is reserved for active danger. Gold means a warning or an opportunity; aqua means a safe or restorative action.

## Typography and controls

Blue Grid is an original bitmap prototype font generated by `tools/GenerateAssets.java`. Use short uppercase labels, avoid long paragraphs inside buttons, and keep body copy at or above the current `0.82` menu scale. Large UI adds 12 percent to menu type and increases button type.

Controls use one shared panel and button family. Every interactive state must include text or geometry in addition to color:

- Selected: `SELECTED` text and checked border.
- Locked: `LOCKED` text, disabled control and unlock requirement.
- Purchasable: `AVAILABLE TO BUY` plus an explicit salvage price.
- Unaffordable: `NEED SALVAGE` plus the required amount.
- Maximum: `MAXIMUM` or `MAXIMUM LEVEL`; the action is disabled.

Touch targets remain at least 84 logical pixels high in menus. Wrapped labels must have reserved vertical space. The Scene2D menu viewport adapts to portrait and wide windows; platform safe insets are converted into world units before the frame width is calculated. Gameplay keeps its 540 by 960 logical composition and uses a fit viewport.

## Screen guidance

- Main menu: one clear route per full-width control; Settings, Credits and Privacy remain directly reachable.
- Level Select: show sector number, region, stars, lock state and highest cleared difficulty before opening the briefing. The briefing owns difficulty selection and launch.
- Hangar: lead with the active combined loadout. Submarine cards compare hull, damage, speed and shield with the current frame. Pilot cards state passive percentages.
- Result: lead with outcome and stars, then mission score and salvage, then the four performance measures. The before/after panel is the emotional payoff.
- Settings: group audio first, comfort/accessibility second and development-only profile reset last.

## Effects language

The runtime renderer already supplies bubbles and suspended water motes, current contours, submarine engine bubbles, cleanup beams, shield rings, sonar pulses, hit feedback, boss warning geometry and restoration-driven palette changes. These effects communicate state before they decorate it.

Reduced effects lowers background geometry, fish and burst particles. Reduced flashes keeps the damaged submarine visible and uses a stable damage ring. Screen shake is short, local to the world camera and never moves the HUD. High-contrast telegraphs add white opposing warning markers; hazard shape, position and motion remain meaningful without color.

## Asset and rendering policy

The build has no sprite atlas because it has no packaged sprite textures. Creating an empty atlas would add complexity without reducing texture switches. When final raster sprites are introduced, group them by screen lifetime into `ui.atlas`, `world-common.atlas` and optional region atlases, with padding and duplicate-padding enabled. AssetManager must own those atlases and their disposal.

All packaged assets must pass `verifyAssetLicenses`. Missing audio degrades to silence, and a missing Blue Grid font uses the libGDX embedded Apache-2.0 fallback so the player can still reach menus. Every final replacement needs source, creator, license, path and usage notes in `assets/licenses/ASSET_LICENSES.md` before it can enter the allowlist.
